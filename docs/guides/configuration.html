Configuration

Environment variables reference for DerList.

All configuration is done via environment variables in a .env file at the project root. Copy .env.example to get started:

cp .env.example .env

Environment Variables

Variable Description Required Default
NEXT_PUBLIC_APP_NAME Application display name shown in the UI No DerList
NEXT_PUBLIC_APP_URL Public URL of the application (used for links, sharing) No http://localhost:3000
DATABASE_URL PostgreSQL connection string Yes —
AUTH_SECRET Secret key for signing session tokens (min 32 characters) Yes —
AUTH_SESSION_DAYS Number of days before a session expires No 30
PROVIDER_ENCRYPTION_KEY AES-256 key for encrypting provider API keys at rest Yes —
UPLOAD_DIR Directory path for uploaded files (relative or absolute) No ./uploads
LOG_LEVEL Logging verbosity: debug, info, warn, error No info
RATE_LIMIT_ENABLED Enable rate limiting on API endpoints No true
NEXT_PUBLIC_ENABLE_ANALYTICS Enable client-side analytics (feature flag) No false
NEXT_PUBLIC_ENABLE_DEBUG Enable debug mode in the UI (feature flag) No false

Generating the Encryption Key

The PROVIDER_ENCRYPTION_KEY is used to encrypt third-party API keys (OpenRouter, SerpAPI, etc.) before storing them in the database. Generate one with:

npm run generate-encryption-key

This outputs a base64-encoded AES-256 key. Copy it into your .env file.

Important: If you lose this key, all stored provider configurations will become unreadable and need to be re-entered.

Database URL Format

DATABASE_URL="postgresql://USER:PASSWORD@HOST:PORT/DATABASE?schema=public"

Examples:

# Local development
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/derlist"

# Remote server
DATABASE_URL="postgresql://derlist_user:s3cur3p4ss@db.example.com:5432/derlist_prod"

Feature Flags

Feature flags use the NEXT_PUBLIC_ prefix so they are available on both server and client:

  • NEXT_PUBLIC_ENABLE_ANALYTICS — When true, loads analytics tracking scripts
  • NEXT_PUBLIC_ENABLE_DEBUG — When true, shows debug panels and verbose logging in the browser console
