Getting Started

Install and run DerList on your own server in minutes.

Prerequisites

  • Node.js 20+ — nodejs.org
  • PostgreSQL 15+ — postgresql.org
  • pnpm (recommended) or npm

1. Clone the Repository

git clone https://github.com/codeboy2012/DerList.git
cd DerList

2. Install Dependencies

# Using pnpm (recommended)
pnpm install

# Or using npm
npm install

3. Configure Environment Variables

Copy the example environment file and fill in required values:

cp .env.example .env

At minimum, configure these variables:

Variable Description
DATABASE_URL PostgreSQL connection string, e.g. postgresql://user:password@localhost:5432/derlist
AUTH_SECRET Random secret for session signing (min 32 characters)
PROVIDER_ENCRYPTION_KEY Encryption key for provider API keys. Generate with: npm run generate-encryption-key

See the Configuration page for the full list of environment variables.

4. Set Up the Database

Create the database if it doesn't exist, then run migrations and generate the Prisma client:

# Create database (if needed)
createdb derlist

# Run migrations and generate client
npx prisma migrate deploy && npx prisma generate

5. Seed the Database

Create the default admin account and initial data:

npx prisma db seed

6. Start the Development Server

npm run dev

Open http://localhost:3000 in your browser.

First Login

The database seed creates a default admin account. Use the credentials printed by the seed script to log in for the first time. You can change the password and configure additional users from the admin panel.

Production Build

npm run build
npm start

For production, ensure AUTH_SECRET and PROVIDER_ENCRYPTION_KEY are strong, unique secrets. Set NEXT_PUBLIC_APP_URL to your public domain.
