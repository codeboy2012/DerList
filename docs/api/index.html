API Reference

REST API endpoints for DerList. All endpoints require authentication unless noted otherwise.

Authentication

All API requests must include a valid session cookie. Sessions are created via the login flow and use SHA-256 hashed tokens stored in the database.

Wishlists

Add Item to Wishlist

MethodPOST
Path/api/wishlists/add-item
AuthRequired
Content-Typeapplication/json or multipart/form-data

Request Body (JSON):

{
  "wishlistId": "string",
  "title": "string",
  "url": "string (optional)",
  "description": "string (optional)",
  "price": "number (optional)",
  "image": "string (optional)",
  "category": "string (optional)"
}

Response: 201 — Created wishlist item object.

Get / Update / Delete Wishlist Item

MethodsGET, PATCH, DELETE
Path/api/wishlists/items/[id]
AuthRequired

GET — Returns the full item with all fields including metadata, specifications, and price history.

PATCH — Partial update. Send only the fields you want to change.

DELETE — Removes the item from the wishlist. Returns 204 No Content.

Copy Wishlist

MethodPOST
Path/api/wishlists/copy
AuthRequired
 
{

  "title": "string (optional, defaults to 'Copy of ...')",
  "includeCategories": "boolean (default: true)",

Organize Wishlist (AI)

MethodPOST
Path/api/wishlists/organize
AuthRequired
 
{
  "wishlistId": "string",
  "mode": "analyze | apply",
  "operations": ["rename", "categorize", "deduplicate"]
}

Response (analyze): 200 — Preview of proposed changes.

Response (apply): 200 — Summary of applied changes.

Path/api/products/search
AuthRequired
 
{

Providers

List / Create / Delete Providers

MethodsGET, POST, DELETE
Path/api/providers
AuthRequired

GET — Returns all configured providers for the current user.

POST — Create a new provider configuration:

{
  "category": "ai | search | price",
  "providerId": "openrouter | openai | serpapi | keepa",
  "name": "string",
  "config": { "apiKey": "string", ... },
  "priority": "number",
  "enabled": "boolean"
}

DELETE — Remove a provider by ID (passed as query param).

Test Provider Connection

MethodPOST
Path/api/providers/[id]/test
AuthRequired

Response: 200 — { "success": true, "latency": 230 } or error details.
